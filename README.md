# Mangayomi Novels PT-BR

Extensão de novels do BR Yaoi para Mangayomi.

A extensão usa a categoria:
https://bryaoi.com/category/novel/

Ela lista as novels, abre a página da obra, coleta os capítulos e entrega o HTML do texto ao leitor de novels do Mangayomi.

## Publicação

Substitua `SEU_USUARIO` nos arquivos `novel_index.json` e `repo.json` pelo seu usuário do GitHub e publique esta pasta em um repositório público chamado `mangayomi-novels-ptbr`.

Depois, adicione no Mangayomi:

https://raw.githubusercontent.com/SEU_USUARIO/mangayomi-novels-ptbr/main/novel_index.json

A extensão não hospeda nem copia capítulos; ela acessa as páginas públicas da fonte.
